Introducción

En esta práctica se desarrollaron cinco aplicaciones web para generar respaldos de una base de datos PostgreSQL alojada en Neon mediante pg_dump.

Marco teórico

PostgreSQL es un gestor de bases de datos relacional que incorpora la utilidad pg_dump para crear copias de seguridad lógicas. Neon proporciona PostgreSQL en la nube con conexiones seguras SSL. Cada lenguaje utilizado implementó una interfaz web con un botón que ejecuta el respaldo y descarga el archivo SQL.

Paso 2

Paso 5

Se presionó el botón Generar respaldo y se confirmó la descarga automática del archivo SQL creado desde la base de datos de Neon.
